# Скриншоты работы приложения

Сюда кладутся скриншоты **реального** окна приложения (запуск: `python src/app/main.py`).
Рекомендуемый набор (имена файлов можно оставить такими):

| Файл | Что показать |
|---|---|
| `01_login.png` | форма входа |
| `02_catalog.png` | каталог: карточки, видны подсвеченные красным модели (остаток 0, 2, 3) и заглушка у Power Urban |
| `03_filters.png` | поиск + фильтр категории + сортировка по цене вместе |
| `04_product.png` | окно модели (клик по карточке): описание, таблица вариантов, выбран вариант — видны цена и «N шт.»; для остатка 0 — «Недоступно для заказа» |
| `05_cart.png` | корзина с позициями и итогом |
| `06_orders.png` | список заказов (менеджер/администратор), даты ДД.ММ.ГГГГ |
| `07_order_detail.png` | состав заказа 3 с исторической ценой (23 200,00 руб.) |
| `08_admin_edit.png` | администратор: изменение даты / удаление строки с подтверждением |
